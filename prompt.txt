## 📦 DADOS (CATEGORIAS E SUBCATEGORIAS)

As categorias devem ser **parametrizáveis** via um único arquivo JSON: `src/data/categories.json`.

**Regras:**
- O JSON é a **única fonte de verdade** dos dados — nenhum componente deve ter dados hard-coded.
- Estrutura: array de categorias, cada uma com `id`, `name`, `icon`, `count` e `subcategories[]` (aninhadas).
- Editar uma categoria ou subcategoria deve ser tão simples quanto editar uma linha do JSON.
- O app importa o JSON diretamente (`import categories from './data/categories.json'`) — preparado para no futuro ser substituído por um `fetch()` a uma API real sem alterar componentes.

**Schema esperado:**

```json
[
  {
    "id": "administracao-publica",
    "name": "Administração Pública",
    "icon": "building",
    "count": 122,
    "subcategories": [
      { "id": "processos-protocolos", "name": "Processos e Protocolos", "count": 69 },
      { "id": "tecnologia-sistemas", "name": "Tecnologia, Sistemas e Inovação", "count": 33 },
      { "id": "compras-contratos", "name": "Compras, Contratos e Fiscalização", "count": 13 },
      { "id": "capacitacao-servidores", "name": "Capacitação de Servidores", "count": 7 }
    ]
  }
]
```

**Gere o `categories.json` completo** com todas as 12 categorias e subcategorias listadas no final deste prompt.

### 7. 🔌 Estratégia MCP com Playwright (EXECUTE AGORA)

**Antes de gerar qualquer código**, utilize as ferramentas do Playwright MCP para inspecionar a página real:

**Passo 1 — Navegação**
Use `mcp__playwright__browser_navigate` para acessar `https://www.ms.gov.br`.

**Passo 2 — Screenshot**
Use `mcp__playwright__browser_screenshot` para capturar o estado visual e identificar o layout da seção de categorias.

**Passo 3 — Snapshot de Acessibilidade**
Use `mcp__playwright__browser_snapshot` para extrair a árvore semântica (roles, labels, hierarquia) da seção de categorias.

**Passo 4 — Interação (se necessário)**
Se as subcategorias estiverem colapsadas, use `mcp__playwright__browser_click` para expandi-las e tire um novo snapshot.

**Passo 5 — Mapeamento para Componentes**
Com base no que foi extraído, identifique:
- Seletores/classes dos containers de categoria
- Estrutura real dos ícones (SVG inline, `<img>`, icon font?)
- Marcação HTML das subcategorias
- Comportamento de interação (hover, click, expand)

Use esses dados para gerar componentes React que reflitam a estrutura **real** da página.
